# Two-Stage CMOS Operational Transconductance Amplifier (OTA)

[![Docs](https://img.shields.io/badge/Docs-purple?style=for-the-badge)](https://squareybrow.github.io/two_stage_cmos_ota/)

This repository contains the transistor-level design, simulation data, and performance analysis for a Two-Stage Miller-Compensated CMOS OTA.

## Tools & Technologies
* **Schematic Capture:** Xschem
* **Simulation Engine:** Ngspice
* **Process Node:** 1 µm CMOS (Level 3 SPICE Model)

## Repository Structure
- `\schematic` - Contains the schematic of the OTA and it's testbenches.
- `\simulations` - Contains simulation data of op, ac, dc, tran analysis.
- `\ota_doc` - Documentation hosted on gh-pages.
